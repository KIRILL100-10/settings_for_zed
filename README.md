# My Zed Editor Configuration 🚀

Minimal, clean, and private configuration for Zed Editor on Manjaro Linux, featuring comprehensive and optimized multi-language support.

This configuration is tailored for developers who want a snappy, privacy-focused editor without losing rich IDE features like formatting on save, precise language server tuning, and custom file associations.

## ✨ Features
* **Privacy First:** Telemetry, diagnostics sharing, and AI features are completely disabled.
* **Extensive Language Support:** Out-of-the-box optimized configs for 15+ languages (Python, Go, Rust, JS/TS, PHP, C/C++, SQL, Docker, etc.).
* **Modern Tooling:** Integrated with top-tier formatters and linters like `biome`, `ruff`, `shfmt`, and `sql-formatter`.
* **Clean UI:** Clean workspace with hidden scrollbars, visible whitespaces only on boundaries, and the *Snazzy Theme*.

## 🛠️ Installation

1. Open your Zed configuration file (via `Ctrl + ,`).
2. Replace the contents with the `settings.json` from this repository.
3. Make sure you have the required formatters/LSPs installed on your system.
